# Barbie Math Adventure

A fun, educational math game for girls with a Barbie theme! Inspired by Prodigy Maths, this game makes learning math fabulous and fun.

## Features

### Educational Content
- **Grade levels K-5**: Age-appropriate math problems for different skill levels
- **Multiple math categories**: Counting, Addition, Subtraction, Multiplication, Division, Fractions
- **Word problems**: Barbie-themed story problems to make math relatable
- **Adaptive difficulty**: Easy, Normal, and Hard modes

### Gameplay
- **Adventure World Map**: 20 levels across 4 themed worlds
  - Barbie's Dreamland
  - Enchanted Forest
  - Ocean Kingdom
  - Sky Castle
- **Battle System**: Defeat cute enemies by solving math problems
- **Boss Battles**: Challenge yourself against special boss characters
- **Streak System**: Build combos for bonus rewards

### Customization
- **Character Creator**: Design your own avatar
  - Multiple hair styles and colors
  - Various skin tones
  - Unlockable outfits and accessories
- **Fashion Boutique**: Earn coins and gems to buy new items

### Progression
- **Level System**: Gain XP and level up
- **Star Ratings**: Earn up to 3 stars per level
- **Achievements**: 18 achievements to unlock
- **Currency System**: Coins and gems for rewards

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Node.js (optional, for development server)

### Running the Game

**Option 1: Open directly**
Simply open `index.html` in your web browser.

**Option 2: Development server**
```bash
npm install
npm start
```

Then open `http://localhost:3000` in your browser.

## Math Topics by Grade

### Kindergarten
- Counting objects (1-10)
- Number recognition
- Simple comparison (>, <, =)
- Addition with sums up to 10

### Grade 1
- Addition within 20
- Subtraction within 20
- Word problems

### Grade 2
- Two-digit addition
- Two-digit subtraction
- Introduction to multiplication (groups)

### Grade 3
- Multiplication tables (2-10)
- Basic division
- Mixed operations

### Grade 4
- Multi-digit multiplication
- Long division
- Simple fractions
- Order of operations

### Grade 5
- Decimal operations
- Fraction operations
- Percentages
- Advanced order of operations
